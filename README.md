# Express Products API

A layered REST API built with Node.js, Express 5, and ES modules. Product data is stored in `src/data/products.json`.

## Run locally

```sh
npm install
npm run dev
```

The server listens on port `3000` by default, or on `PORT` if it is set. Use the [REST Client extension for VS Code](https://marketplace.visualstudio.com/items?itemName=humao.rest-client) to run requests from [`requests.http`](./requests.http).

## Product fields

Create and full-replacement requests require all of these fields:

| Field | Validation |
| --- | --- |
| `name` | String, 2–100 characters |
| `sku` | Unique string matching `^[A-Z]{3}-\d{4}$` |
| `category` | One of `Accessories`, `Apparel`, `Electronics`, `Home`, `Outdoors`, `Stationery` |
| `price` | Number greater than 0 |
| `stock` | Integer greater than or equal to 0 |

Product `id` and `createdAt` are generated by the API. PATCH requests may include one or more editable fields. Successful JSON responses use `{ "data": ... }`; errors use `{ "error": { "message": "...", "fields": {} } }` when field details apply.

## Endpoints

| Method | Path | Body | Success code | Error codes |
| --- | --- | --- | --- | --- |
| GET | `/api/health` | — | 200 | 500 |
| GET | `/api/products` | —; optional `category`, `q`, and `sort=price` (ascending) or `sort=-price` (descending) query parameters | 200 | 500 |
| GET | `/api/products/:id` | — | 200 | 404, 500 |
| POST | `/api/products` | All product fields | 201 (`Location` header) | 400, 422, 500 |
| PUT | `/api/products/:id` | All product fields; replaces editable fields | 200 | 400, 404, 422, 500 |
| PATCH | `/api/products/:id` | One or more product fields | 200 | 400, 404, 422, 500 |
| DELETE | `/api/products/:id` | — | 204 (no response body) | 404, 500 |

Unknown routes return 404. Malformed JSON returns 400; valid JSON with invalid product fields returns 422.

## Example curl commands

In PowerShell, list products with filters and sorting:

```sh
curl.exe "http://localhost:3000/api/products?category=Home&q=lamp&sort=price"
```

Create a product (the response includes its generated ID and a `Location` header):

```sh
curl.exe -i -X POST http://localhost:3000/api/products -H "Content-Type: application/json" -d '{"name":"Desk Organizer","sku":"DSK-1200","category":"Home","price":24.5,"stock":12}'
```

Update one field:

```sh
curl.exe -X PATCH http://localhost:3000/api/products/PRODUCT_ID -H "Content-Type: application/json" -d '{"stock":8}'
```

Delete a product:

```sh
curl.exe -i -X DELETE http://localhost:3000/api/products/PRODUCT_ID
```
